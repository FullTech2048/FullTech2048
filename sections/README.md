# Profile README — Modular Sections

GitHub only renders the root `README.md` on your profile.
These files document each section so you can edit one part at a time without hunting through a giant file.

| File | Section |
| --- | --- |
| `01-header.md` | Capsule banner + typing roles + badges |
| `02-about.md` | Bio & status |
| `03-roles.md` | Engineering hats grid |
| `04-tech.md` | Tech stack badges |
| `05-stats.md` | Stats / streak / activity graph |
| `06-snake.md` | Contribution snake (GitHub Action) |

**Workflow:** edit the matching block in root `README.md` (search for `===== 0N ·`), then push to `main`.
