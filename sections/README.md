# Profile README — Modular Sections

GitHub only renders the root `README.md` on your profile.
These files document each section so you can edit one part at a time.

| File | Section |
| --- | --- |
| `01-header.md` | Capsule banner + typing roles |
| `02-about.md` | Profile bio & focus table |
| `03-roles.md` | Engineering domains |
| `04-tech.md` | Stack / skillicons |
| `05-stats.md` | Stats + streak |
| `06-snake.md` | Contribution snake (GitHub Action) |
| `07-selected-work.md` | Selected work + pin cards |

**Workflow:** edit the matching block in root `README.md`, then push to `main`.
